# 🌐 WebNest — Useful Websites & Online Tools

**WebNest** is a simple, fast, and student-friendly web directory for discovering useful websites and online tools for **AI, coding, study, design, careers, productivity, PDFs, images, and everyday tasks**.

The project provides a clean interface where users can search, filter, sort, favorite, and randomly discover useful websites.

## ✨ Features

* 🔎 **Search websites** by name, category, or description
* 📚 **Browse by category**
* ❤️ **Save favorite websites** using browser `localStorage`
* 🎲 **Surprise Me** to discover a random website
* 🔤 **Sort websites** by:

  * Featured
  * A → Z
  * Favorites first
* 🌙 **Dark mode**
* 📱 **Responsive design** for desktop, tablet, and mobile
* 🪟 **Website details modal**
* 🔗 **Open websites in a new tab**
* 🔄 **Reset filters**
* ⚡ Smooth scrolling and interactive UI effects

The HTML structure includes dedicated sections for categories, the website collection, project information, statistics, and the website-detail modal.

### `index.html`

Contains the main structure of the website, including:

* Navigation bar
* Hero section
* Search interface
* Category section
* Website cards
* About section
* Statistics
* Modal dialog
* Footer

The page loads the external `style.css` and `script.js` files.

### `style.css`

Contains the complete visual design, including:

* CSS variables and theme colors
* Responsive layouts
* Cards and buttons
* Hero section
* Animations
* Dark mode
* Modal styling
* Mobile breakpoints

The design uses the **Inter** font and a purple/indigo visual theme.
